DIGITAL DETECTIVE GAMES

Versão 1.0.0

Missão

O Digital Detective Games é uma plataforma de jogos clássicos desenvolvida como refatoração do projeto GameLab original. O objetivo é demonstrar habilidades em desenvolvimento web através de uma interface nostálgica inspirada no Windows 98, combinada com uma paleta de cores moderna e corporativa.

Conceito

Criamos uma experiência única onde jogos clássicos são apresentados como "aplicativos" em um ambiente de desktop simulado. Cada jogo funciona em janelas modais independentes que podem ser arrastadas, redimensionadas e gerenciadas, proporcionando uma experiência nostálgica e funcional.

Tecnologias

  • HTML5
  • CSS3
  • JavaScript ES6+
  • Web Audio API
  • LocalStorage API
  • Canvas API
  • Font Awesome
  • Google Fonts

Jogos Disponíveis

  • ⚔️ Tic-Tac-Toe: Jogo da velha com IA invencível usando algoritmo Minimax
  • 💣 Campo Minado: Clássico jogo de campo minado com 3 níveis de dificuldade
  • 🕵️ Jogo da Forca: Adivinhe palavras com sistema de categorias e dicas
  • 🏓 Pong: O primeiro videogame da história com física realista
  • 🧠 Memory Game: Teste sua memória encontrando pares de cartas

Design

A paleta de cores foi cuidadosamente selecionada para criar uma identidade visual única, combinando tons de cinza com vermelho vibrante. O design das janelas foi inspirado no icônico Windows 98, trazendo nostalgia enquanto mantém a usabilidade moderna.

Cores principais:
• Cinza Escuro (#242424) - Base e backgrounds
• Cinza Médio (#808080) - Elementos secundários
• Vermelho (#FD0100) - Destaques e interações
• Cinza Claro (#CBDCC1) - Textos e contraste
