Funcionalidades

Janelas Modais
Cada jogo funciona em uma janela independente, que pode ser arrastada, redimensionada, minimizada e maximizada.
5 Jogos Clássicos
Tic-Tac-Toe, Campo Minado, Jogo da Forca, Pong e Memory Game, todos com IA e múltiplos níveis de dificuldade.
Persistência de Dados
Todas as estatísticas, pontuações e recordes são salvos localmente e persistem entre sessões.
Design Responsivo
Interface adaptável que funciona perfeitamente em desktops, tablets e dispositivos móveis.
Tema Windows 98
Design nostálgico inspirado no Windows 98 com paleta de cores corporativa moderna.
Código Limpo
Código bem documentado, modular e seguindo boas práticas de desenvolvimento JavaScript ES6+.

Jogos Disponíveis

Tic-Tac-Toe
Jogo da velha com IA baseada em Minimax. Jogue contra o computador ou com um amigo no modo 2 jogadores.
Campo Minado
Clássico jogo de campo minado com três níveis de dificuldade. Use bandeiras para marcar as minas suspeitas.
Jogo da Forca
Adivinhe a palavra antes que o boneco seja completado. Inclui sistema de categorias e dicas.
Pong
O primeiro videogame da história recriado. Jogue contra uma IA com três níveis de dificuldade.
Memory Game
Teste sua memória encontrando todos os pares. Três tamanhos de tabuleiro disponíveis.
Snake
O clássico jogo da cobrinha. Coma a comida, cresça e evite bater nas paredes ou em você mesmo!

Tecnologias Utilizadas

  • HTML5 - Estrutura semântica moderna
  • CSS3 - Grid Layout, Flexbox, Custom Properties
  • JavaScript ES6+ - Classes, Arrow Functions, Template Literals
  • Web Audio API - Efeitos sonoros procedurais
  • LocalStorage API - Persistência de dados
  • Canvas API - Renderização de gráficos 2D
  • Font Awesome - Ícones vetoriais
