# 🎮 Digital Detective Games

Plataforma de jogos clássicos com interface Windows 98.

## 🕹️ Jogos Disponíveis

1. **Tic-Tac-Toe** ⚔️ - Jogo da velha com IA invencível
2. **Campo Minado** 💣 - Clássico jogo de minas (3 dificuldades)
3. **Jogo da Forca** 🕵️ - Adivinhe palavras com dicas
4. **Pong** 🏓 - O primeiro videogame da história
5. **Memory Game** 🧠 - Encontre todos os pares
6. **Snake** 🐍 - Jogo clássico da cobrinha
7. **Wordle** 🔤 - Adivinhe a palavra de 5 letras
8. **Paciência** 🃏 - Solitaire Klondike clássico

## 🚀 Como Usar

1. Abra `index.html` no navegador
2. Dê **duplo clique** em qualquer ícone para abrir o jogo
3. Arraste, redimensione e gerencie as janelas como no Windows 98

## 🎨 Estilo Windows 98

- Desktop com fundo cinza claro
- Ícones 3D clássicos
- Barra de tarefas funcional
- Janelas arrastáveis e redimensionáveis
- Menu Start com opções

## 💾 Estatísticas

Todos os jogos salvam estatísticas localmente:
- Pontuações
- Recordes
- Total de partidas

## 🔧 Tecnologias

- HTML5, CSS3, JavaScript ES6+
- Web Audio API (sons)
- LocalStorage API (persistência)
- Canvas API (gráficos)
